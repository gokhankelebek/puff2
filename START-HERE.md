# Puff Vegas — start here

A new website for **Puff Vegas Smoke & Vape Shop**, Grand Bazaar Shops, Las Vegas
Strip. It replaces the shop's Ecwid storefront.

**Status: LIVE on puffvegas.us since 2026-09-29** (Vercel project `puff2`, GitHub `main` → auto-deploy). DNS stays at Bluehost: A `@` → 216.150.1.1, CNAME `www` → Vercel. To roll back to Ecwid, point both at 34.193.83.23.

```bash
cd web && npm install && npm run dev
```

`npx tsc --noEmit` in `web/` is the typecheck. There is no test suite yet.

> **Restart the dev server after touching `next.config.ts`.** HMR does not reload
> it, so redirects silently don't apply — a server left running for a day will
> happily serve a route that has since moved.

## Where things stand

> **This tree is mid-redesign.** It is a copy of `~/puff` with the presentation
> layer stripped: the site builds and every route serves, but it is deliberately
> unstyled while a new design is brought in. The inventory and everything behind
> the commerce adapter are untouched. The `origin` remote was removed on purpose —
> `puff2026.git` is the old site's public repo and must not receive this work.
> Revert point: the commit *"Baseline: copy of puff before presentation strip"*.

**Built and working:** homepage with Pick-Up / Delivery · six department pages · product
pages · catalogue search (server + typeahead sharing one scorer) · age gate ·
day/night toggle · `/pickup` walk-in · `/delivery` hotel picker with
pre-filled SMS.

**Catalogue:** 1,415 models imported, **175 published**, all priced, 161 branded,
**172 with background-removed images**.

**Recently settled:** the shop's true coordinate — suite 611-613 at
`36.113777, -115.172005`, *not* Google's Grand Bazaar pin, which is 85 m away and
outside the mall footprint. See [docs/LOCATION.md](docs/LOCATION.md).

**Biggest open items:** the counsel questions in [docs/OPEN-DECISIONS.md](docs/OPEN-DECISIONS.md) — the site is now public.

## Two things that will bite you

1. **This is Next.js 16.3.1 and it has breaking changes.** `web/AGENTS.md` is
   regenerated by `next dev` and says to read `web/node_modules/next/dist/docs/`
   before writing framework code. Do that. `headers()` and `searchParams` are
   async here.

2. **The owner knows this corner better than any dataset.** Walking times were
   published wrong three times because OSRM was trusted over him; he was right
   about "3 minutes from Bellagio" from the start. When his local knowledge
   conflicts with a measurement, check the measurement first.
